# Class icon sources

The class symbols in this directory are 64 px transparent PNG conversions of the
class SVGs displayed by Garmoth's class-popularity and grind-tracker pages:

- Source pattern: `https://assets.garmoth.com/classes/svg/class_icon_{id}.svg`
- Retrieved: 2026-09-06
- Conversion: ImageMagick, transparent background, maximum 64 × 64 px

The symbols depict Black Desert classes. Black Desert and its class artwork are
owned by Pearl Abyss. These files are included only as compact UI identifiers.
