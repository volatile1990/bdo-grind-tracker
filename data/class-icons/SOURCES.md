# Class icon sources

The class symbols in this directory are 64 px transparent PNG conversions of the
class SVGs displayed in Garmoth's **Characters → Create → Select Class** menu:

- Source pattern: `https://assets.garmoth.com/classes/svg/class_icon_{id}.svg`
- Retrieved and mapped from the rendered menu: 2026-09-07
- Conversion: ImageMagick, transparent background, maximum 64 × 64 px

Class-to-ID mapping used by that menu:

`Warrior 0, Hashashin 1, Sage 2, Wukong 3, Ranger 4, Guardian 5, Scholar 6,
Drakania 7, Sorceress 8, Nova 9, Corsair 10, Lahn 11, Berserker 12, Maegu 15,
Tamer 16, Shai 17, Striker 19, Musa 20, Maehwa 21, Mystic 23, Valkyrie 24,
Kunoichi 25, Ninja 26, Dark Knight 27, Wizard 28, Archer 29, Woosa 30,
Witch 31, Seraph 32, Dosa 33, Deadeye 34, Agent 35.`

The symbols depict Black Desert classes. Black Desert and its class artwork are
owned by Pearl Abyss. These files are included only as compact UI identifiers.
