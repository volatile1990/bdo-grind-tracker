# Grindcrest 1.0.2-test.5

- PP-OCRv6 Small über ONNX Runtime ersetzt Tesseract als lokale Zusatzprüfung
  unsicherer Lootzeilen. Windows OCR bleibt der Hauptweg. Modell und Zeichensatz
  werden mitgeliefert; Python und ein Modelldownload beim Start sind nicht nötig.
- Originalbild und Graustufen werden parallel zu anderen Zeilen geprüft.
  Brauchbare primäre Ergebnisse bleiben maßgeblich; reine Mengenwidersprüche
  werden nicht durch Wahl der größeren Zahl aufgelöst.
- Der normale Zähler erhält innere OCR-Lücken als Zeilenpositionen. Später gelesene
  Mengen berichtigen einen Mindestwert unter derselben Drop-ID, ohne die
  Anzahl der Drops zu erhöhen. Wiederholte Mengenrevisionen wirken nur einmal.
- Gelesene Mengen unter dem spotbezogenen Minimum werden auf das Minimum gesetzt;
  das Maximum begrenzt weiterhin jeden einzelnen Drop. Magaia-Trash: Minimum 4.
- Die bisherige Item-Chat-OCR einschließlich ihrer Hinweise entfällt.

Lokale Testversion. Die bisherige Erneuerungsheuristik für nicht unterscheidbare
gleiche Zeilen bleibt erhalten. Im Replay ergeben sich 3.526 statt echter 3.508
und 1.318 statt echter 1.360 Trash. Die zweite dieser Aufnahmen liegt damit weiter
unter dem Istwert als zuvor. Weitere Angaben: docs/BACKGROUND_OCR_REVIEW.md.
