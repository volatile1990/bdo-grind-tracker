Grindcrest ist jetzt als Windows-Installer mit integrierter Updatefunktion verfügbar.

- **Installation:** `Grindcrest-win-x64-beta-Setup.exe` herunterladen und ausführen. .NET ist enthalten; fehlendes WebView2 und Visual C++ werden bei Bedarf installiert.
- **Updates:** Unter Einstellungen → App-Updates neue Versionen prüfen und herunterladen. Die Installation erfolgt auf Klick bei pausierter Session; der Verlauf wird vorher gespeichert.
- **Vorhandene Daten:** Einstellungen, Verlauf und der gespeicherte Garmoth-Key werden am bisherigen Speicherort weiterverwendet. Nutzer einer entpackten Version führen den Installer einmal aus.
- **Beta-Kanal:** Diese Ausgabe ist eine Testversion. Beta-Updates können in den Einstellungen ausgeschaltet werden; dann wartet Grindcrest auf eine höhere stabile Version.
- **Aktueller Projektstand:** Favoriten und Verbesserungen am Verlauf, an den Marktpreisen und an der gespeicherten Fensterposition sind enthalten.

Der aktuelle Tracker-Stand mit Blazor-Oberfläche, Item-Chat-Mengenfallback und lokaler Fehlerdiagnose ist enthalten. Die Loot-Erkennung sollte weiterhin im Spiel mit dem tatsächlichen Inventarloot verglichen werden.

Der Installer ist derzeit **nicht digital signiert**. Windows kann deshalb eine Sicherheitswarnung anzeigen.

Für reguläre Nutzung den Setup herunterladen. Die `.nupkg`- und `.json`-Dateien benötigt die Updatefunktion; sie werden nicht manuell geöffnet.
