# Grindcrest 1.0.1

- Microsoft-Store-Ausgabe: Hinweise auf neue Versionen direkt in Grindcrest, beim Start und nach jeweils sechs Stunden weiterer Nutzung.
- Updates direkt in den Einstellungen herunterladen und installieren, einschließlich Fortschritt und verständlicher Fehler-/Abbruchmeldungen.
- Installation erst bei pausierter, nicht beschäftigter Session und nach erfolgreicher Speicherung von Verlauf, Einstellungen und Fensterposition. Bei Fehlern oder Abbruch bleibt die App benutzbar.
- Windows übernimmt die Paketinstallation und kann einen Bestätigungsdialog anzeigen oder die App schließen. Grindcrest registriert sich für einen von Windows ausgelösten Neustart nach dem Update; falls dieser ausbleibt, kann die App erneut geöffnet werden.
- GitHub-Installationen behalten ihren bisherigen Updatekanal. Store-Installationen verwenden ausschließlich die Store-Schnittstelle.

Die Funktion wird erst mit Installation dieser Version verfügbar. Ein bereits installiertes Store-Paket 1.0.0 erhält 1.0.1 zunächst über die normale Store-Updatefunktion (automatisch, sofern aktiviert).
