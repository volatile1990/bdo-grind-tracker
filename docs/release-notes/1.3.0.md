# Grindcrest 1.3.0

Dieses Minor-Release verbessert den Start einer Grind-Session, die
Agris-Erkennung und die Übersicht der Drops. Es baut auf
[Grindcrest 1.2.3](1.2.3.md) auf.

- **Aktive Zeit ab dem ersten Drop:** Nach Start oder Fortsetzen beginnt die
  Zeitmessung erst mit dem ersten neu erkannten Drop. Die Wartezeit davor zählt
  nicht zur aktiven Grindzeit; bereits erfasste Zeit bleibt erhalten. Dashboard
  und Overlay zeigen an, dass die App auf einen Drop wartet. Manuelle
  Lootkorrekturen starten die Zeitmessung nicht.
- **Passende XP- und Agris-Ausgangswerte:** Beim ersten Drop werden die
  Ausgangswerte für den neuen aktiven Abschnitt neu erfasst, damit Änderungen
  während der Wartezeit nicht dem Grind zugerechnet werden. Sessions mit bereits
  erfasstem Loot bleiben auch bei einer aktiven Zeit von unter einer Sekunde im
  Verlauf erhalten.
- **Agris bei HDR zuverlässiger erkennen:** Auch sehr helle, beinahe weiße
  Agris-Symbole mit warmem Farbton und aktivem Ring werden als aktiv erkannt.
  Die Erkennung unterscheidet weiterhin graue und inaktive Symbole.
- **Mehr Platz für Drops:** Suche, Sortierung, Gesamt-/Stundenansicht und
  „Gegenstand ergänzen“ teilen sich bei ausreichender Breite eine kompakte
  Kopfzeile. Bei schmaleren Fenstern ordnen sich die Elemente passend um.
- **Windows-Freigabe verständlich erklärt:** Vor einer noch erforderlichen
  Freigabe erklärt Grindcrest, warum Windows nach dem Aufnahmerahmen fragt und
  was die Auswahl bedeutet. Eine vorhandene Freigabe wird wiederverwendet.
  Der anschließende Systemdialog wird weiterhin von Windows vorgegeben.

Die Store-Paketversion lautet **1.3.0.0**. Das MSIX wird mit der bestehenden
Store-Identität gebaut und enthält die .NET-Laufzeit. Testergebnisse,
Paketprüfung und SHA-256-Prüfsumme werden in den Release-Artefakten dokumentiert.
Das Paket ist zur Einreichung im Microsoft Partner Center bestimmt; der lokale
Build veröffentlicht kein Store-Update.
