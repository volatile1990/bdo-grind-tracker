# Grindcrest 1.0.2-test.4

- Eine OCR-Lesung von 0 ist keine gültige Dropmenge und blockiert deshalb keine
  positive Mengenlesung mehr.
- Bei einem bereits erkannten normalen Item mit fehlender Menge darf die einzige
  gültige Zahl aus einer vollständig gelesenen, passend positionierten Lootzeile
  den Minimum-Fallback ersetzen. Namenszuordnung, Mindestkonfidenz und Maximum
  werden weiterhin geprüft.
- Bereits gelesene positive Mengen behalten ihren Schutz. Ausschließlich isolierte
  Ziffern benötigen weiterhin zwei übereinstimmende Lesungen; echte Mengenwidersprüche
  werden nicht durch Wahl der größeren Zahl aufgelöst.
- Der Magaia-Minimum-Fallback bleibt 4. Die Änderung wurde am Originalbild327 und
  den betroffenen OCR-Prüfungen dreier Aufnahmen getestet.

Lokale Testversion. Der Zählalgorithmus bleibt unverändert.
