# Grindcrest 1.11.2

Dieses Patch-Release verbessert die automatische OCR-Prüfung in der Setup-Tour.
Es baut auf [Grindcrest 1.11.1](1.11.1.md) auf.

- **Passendes OCR-Sprachpaket direkt prüfen:** Beim Start prüft Grindcrest, ob
  die Windows-Texterkennung für die gewählte Spielsprache installiert ist. Ein
  vorhandenes OCR-Paket für eine andere Sprache verdeckt ein fehlendes Paket
  nicht mehr.
- **Aktueller Status im Erfassungsschritt:** Beim Öffnen des Erfassungsschritts
  prüft die Setup-Tour OCR automatisch erneut. Der Status wird ohne zusätzlichen
  Klick auf die OCR-Prüfung angezeigt.
- **Sprachwechsel berücksichtigen:** Nach einem Wechsel der Spielsprache wird
  die OCR-Verfügbarkeit für die neu gewählte Sprache aktualisiert.

Store-Paketversion: **1.11.2.0**. Die lokale Erstellung veröffentlicht kein Update
im Microsoft Store.
