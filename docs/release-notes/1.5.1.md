# Grindcrest 1.5.1

Dieses Patchrelease entfernt den zusätzlichen Erklärdialog zum gelben
Aufnahmerahmen. Es baut auf [Grindcrest 1.5.0](1.5.0.md) auf.

- Trackingstart, Fortsetzen und Erfassungsvorschau benötigen keine Bestätigung
  des eigenen Grindcrest-Erklärdialogs mehr. Das gilt auch beim Start aus dem Overlay.
- Die Aufnahme ohne gelben Rahmen wird weiterhin automatisch bei Windows
  angefordert. Windows entscheidet, ob dafür eine Systemabfrage nötig ist.
- Eine abgelehnte Windows-Freigabe verhindert das Tracking nicht; der gelbe
  Aufnahmeindikator kann dann sichtbar bleiben.

Store-Paketversion: **1.5.1.0**. Die lokale Erstellung veröffentlicht kein Update
im Microsoft Store.
