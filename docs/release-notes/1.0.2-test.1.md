# Grindcrest 1.0.2-test.1

- Korrigiert die starke Unterzählung nach HDR-Umwandlung: Der erste Windows-OCR-
  Durchlauf erhält eine passende Schriftmaske und den vollständigen Itemnamen
  einschließlich Mengensuffix. Der bisherige SDR-Erkennungsweg bleibt erhalten.
- Gute Ergebnisse des ersten Durchlaufs bleiben maßgeblich. Zusätzliche OCR
  bearbeitet nur deutliche Grenzfälle; Hintergrundtext ohne Itemhinweis entfällt.
- Eine vollständige, exakt zugeordnete und gut positionierte Zweitlesung kann
  eine unlesbare Zeile auch dann retten, wenn andere Bildvarianten keine brauchbare
  Schrift liefern. Widersprüche behalten den ursprünglichen Wert.
- Fertige Ergebnisse erscheinen während der Sitzung.

Lokale Testversion. Die vollständige Aufnahme vom 08.09.2026 um 14:16 wurde
erneut mit echter OCR ausgewertet. Der unveränderte Zählalgorithmus bleibt
eine mögliche Quelle verbleibender Über- und Unterzählungen.
