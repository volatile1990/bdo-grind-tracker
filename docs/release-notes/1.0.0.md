# Historische Versionshinweise: 1.0.0

Erste stabile Veröffentlichung des damaligen Grindcrest-Stands für Windows x64.
Die aktuelle Version wird ausschließlich über den
[Microsoft Store](https://apps.microsoft.com/detail/9NQPWC1CMWS0) installiert und
aktualisiert; [Installationshinweise](../MICROSOFT_STORE.md).

- Live-Tracking mit Blazor-Oberfläche, Loot- und Silberwerten sowie automatischer Spoterkennung.
- Lokaler Verlauf mit Lootkorrekturen, Favoriten und gespeicherter Fensterposition.
- Optionale Garmoth-Uploads, einschließlich stündlicher Übertragung.

Diese Veröffentlichung übernahm den damaligen Funktionsstand; die Versionsfreigabe
änderte die Loot-Erkennung nicht. Die heutigen Erkennungsgrenzen stehen in der
[README](../../README.md).

Der damals beschriebene separate Installer und seine Updatekanäle wurden
inzwischen entfernt. Die früheren Anweisungen zum Wechsel von der Testausgabe
und zur Installation von Paketdateien sind nicht mehr anwendbar.
