Erste stabile Veröffentlichung des aktuellen Grindcrest-Stands für Windows x64.

- Live-Tracking mit Blazor-Oberfläche, Loot- und Silberwerten sowie automatischer Spot-Erkennung.
- Lokaler Verlauf mit Lootkorrekturen, Favoriten und gespeicherter Fensterposition.
- Optionale Garmoth-Uploads, einschließlich stündlicher Übertragung.
- Windows-Installer mit integrierter Updatefunktion und getrennten Stable-/Beta-Kanälen.

**Installation:** `Grindcrest-win-x64-stable-Setup.exe` herunterladen und ausführen.
.NET ist enthalten; fehlendes WebView2 und Visual C++ werden bei Bedarf installiert.
Vorhandene Einstellungen, Verlauf und Garmoth-Key werden weiterverwendet.

**Update von 0.10.0-test.2:** In Einstellungen → App-Updates den Schalter
**Beta-Updates erhalten** ausschalten. Anschließend 1.0.0 herunterladen und bei
pausierter Session **Installieren und neu starten** wählen. Vor dem Neustart wird
die Session gespeichert. Alternativ kann der stabile Installer ausgeführt werden.

Diese Veröffentlichung übernimmt den aktuellen Funktionsstand; die Versionsfreigabe
ändert die Loot-Erkennung nicht. Die bekannten Erkennungsgrenzen sind im README dokumentiert.

Der Installer ist derzeit **nicht digital signiert**. Windows kann deshalb eine Sicherheitswarnung anzeigen.

Für reguläre Nutzung den Setup verwenden. Die `.nupkg`- und `.json`-Dateien sind für
die Updatefunktion bestimmt und müssen nicht manuell geöffnet werden.
